# Tree Nests [Bedrock 26.40 Addon]

![Minecraft Version](https://img.shields.io/badge/Minecraft_Bedrock-26.40-brightgreen)

This addon adds randomly spawning nests that can either contain loot or an inhabitant:)

## Features:

* Loot defined in a custom loot table with the ability to inject your own items (powered by [TagLoot API](https://github.com/Chackapon/tagloot-api)
* Random generation based on the world seed
* Supports all types of tree logs (including most* modded!)


\* Entirely depends on if the addon creator used the vanilla minecraft naming convention for logs (ex. "oak_log").
